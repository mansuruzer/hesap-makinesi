# Hesap Makinesi Bul · YTÜ

Sınav haftasında hesap makinesi ödünç alma/verme. Sınav saatinde makinesi boşta olan YTÜ'lüleri listeler, WhatsApp'tan iletişim kurulur.

- Arayüz: tek dosya `index.html` (GitHub Pages)
- Veri: Supabase (`supabase.sql`, `hm_` tabloları; tüm erişim RPC fonksiyonları üzerinden, tablolar RLS ile kapalı)
